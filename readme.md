<h1>Лабораторная работа №3</h1>
<b>Цель</b> работы -  создание веб-сервиса в бэкенде нашей системы для использования его в SPA

<b>Задание</b> - создание веб-сервиса со всей итоговой бизнес логикой (кроме авторизации), подключение его к БД и тестирование в postman

<h2>Структура базы данных</h2>

<b>users</b> - пользователи
id - идентификатор пользователя, первичный ключ - id
login - логин, уникальное значение - login
password - пароль - не отдаётся в JSON
is_moderator - признак модератора, по умолчанию false - не отдаётся в JSON

<b>planets</b> - услуги
id - идентификатор планеты, первичный ключ - id
name - название планеты, обязательное - name
description - описание планеты - description
distance_from_sun - расстояние до Солнца, обязательное - distance_from_sun
perihelion - перигелий - perihelion
observation_date - дата наблюдения - observation_date
image_url - имя файла изображения в MinIO - image_url
url_video - имя файла видео в MinIO - url_video
status - состояние записи: draft, published, deleted - не отдаётся в JSON
user_id - владелец записи, внешний ключ на users - не отдаётся в JSON
created_at - дата и время создания - created_at
updated_at - дата и время изменения - updated_at
likes_count - количество лайков, вычисляется из таблицы likes - likes_count
liked - лайкнул ли текущий пользователь, 0 или 1, вычисляется - liked
is_owner - текущий пользователь владелец записи, 0 или 1, вычисляется - is_owner

<b>likes</b> - лайки
id - идентификатор лайка, первичный ключ - не отдаётся в JSON
user_id - кто поставил лайк, внешний ключ на users - не отдаётся в JSON
planet_id - чья планета, внешний ключ на planets - не отдаётся в JSON
